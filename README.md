# RTL for ChatGPT

תוסף ל־Chrome שמאפשר להחליף בלחיצה את כיוון השיחה ושדה ההקלדה ב־ChatGPT. הוא נועד לקריאה ולכתיבה בעברית ובשפות נוספות שנכתבות מימין לשמאל. קוד ונוסחאות נשארים משמאל לימין, וסדר העמודות בטבלאות נשמר.

## התקנה ושימוש

[התקנת RTL for ChatGPT מחנות התוספים של Chrome](https://chromewebstore.google.com/detail/rtl-for-chatgpt/memhfhjffogebamhkhpjpgjjmkdieaoe)

אפשר להחליף כיוון באמצעות המתג ליד שדה ההקלדה, סמל התוסף בסרגל של Chrome או הקיצור `Alt+Shift+X` (`Option+Shift+X` ב־Mac). אפשר לשנות את הקיצור ב־`chrome://extensions/shortcuts`.
